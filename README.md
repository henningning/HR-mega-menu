# Schlichtes Megamenü Block

WordPress-Plugin von Henning Rolapp. Aktuelle Version: **5.7.0**.

Native WordPress-Menüverwaltung, Megamenü-Spalten, Dropdowns, automatische Inhaltslisten und Gutenberg-Block. Unterstützt horizontale und vertikale Darstellung.

## Installation

Repository als ZIP herunterladen und den enthaltenen Plugin-Ordner nach `wp-content/plugins/` kopieren. Anschließend in WordPress aktivieren.

## Anleitung

Siehe [ANLEITUNG.md](ANLEITUNG.md).

## Voraussetzungen

- WordPress 6.5 oder neuer
- PHP 7.4 oder neuer
